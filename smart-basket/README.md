# 🛒 Smart Basket — סל חכם

מערכת שלומדת את הסל המשפחתי מהקבלות, ובודקת (כשמבקשים, לא אוטומטית) איפה הכי זול לקנות אותו
באונליין בישראל — בחנות אחת, או בפיצול בין שתי חנויות. כולל מבצעים ידניים שלא מופיעים באינטרנט
(למשל "שלישי שוק" בוויקטורי נתיבות).

## איך זה עובד

```
 צילומי קבלות ──► Claude מתמלל ──► data/receipts/*.json ──► receipt import ──► data/catalog.json
                                                                                 (המוצרים שלנו: קבוע / מזדמן / מועמד)
 קבצי מחירים רשמיים (חוק שקיפות מחירים) ──► fetch ──► data/prices.db
                                                              │
 data/manual_deals.json (שלישי שוק...) ─────────────────────► compare ──► חנות זולה / פיצול לשתיים
```

- **מחירים**: לא "גירוד" של אתרי הקניות, אלא קבצי ה-XML שהרשתות מחויבות לפרסם בחוק (מחיר, ברקוד,
  גודל, מבצעים — לכל סניף, כולל הסניף האינטרנטי). מקור יציב ומדויק יותר.
- **מוצר קבוע** (ברקוד) — "חלב תנובה 3% 1 ל'". **מוצר גמיש** — "עגבניות", "אורז 1 ק"ג כל מותג" —
  נבחר הזול ביותר לפי מחיר לק"ג/ליטר.
- **למידה**: מוצר שמופיע ב-40% מהקבלות האחרונות הופך ל"קבוע" ונכנס לכל השוואה. כמות לקנייה = החציון.

## הפעלה

```bash
cd smart-basket
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

python -m basket fetch                    # הורדת מחירים עדכניים
python -m basket compare --date 2026-11-24
python -m web.app                         # ממשק: http://127.0.0.1:8765
```

פקודות נוספות: `python -m basket --help` (search, offers, stores find, catalog, receipt import).

## עבודה עם Claude

- **מעלים צילום קבלה** בשיחה → Claude מתמלל, מייבא, מתאים ברקודים, שואל רק מה שצריך.
- **"תבדוק מחירים לשלישי"** → Claude מוריד מחירים, מריץ השוואה ומסביר את ההמלצה.
- **צילום שלט/פלאייר של שלישי שוק** → Claude מעדכן את `data/manual_deals.json`.

ההוראות המלאות ל-Claude: [`CLAUDE.md`](CLAUDE.md). הזיכרון: `memory/` + `data/`.
