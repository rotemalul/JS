# 🌍 מסביב לעולם

משחק לילה־טוב להכרת מדינות העולם, לילדים בגילאי 5–8.
האפיון המלא: [SPEC.md](SPEC.md)

## איך מריצים

פשוט פותחים את `index.html` בדפדפן — אין צורך בהתקנה או בשרת.
(לחוויה הכי טובה: טאבלט או מסך מגע, ודפדפן עם קול עברי ל־Web Speech API.)

```bash
# או עם שרת מקומי:
npx http-server world-explorer
```

## מה יש בגרסה הזו (MVP — שלב 1)

- 🗺️ מפת מדינות עם "המדינה של הלילה" — 5 מדינות, אחת מכל יבשת (ישראל, איטליה, יפן, ברזיל, קניה)
- 🎈 מסך ביקור עם 8 בועות גילוי: דגל, עיר בירה, מיקום, מאכלים, חיות, מקום מיוחד, שפה, אנשים מיוחדים
- 🎲 3 משחקונים: מצאו את הדגל, מי גר כאן, פאזל דגל — בסדר אקראי, בלי כישלונות ובלי לחץ
- 🛂 דרכון עם חותמות ואלבום מדבקות (נשמר ב־localStorage)
- 🗣️ קריינות בעברית (Web Speech API) + צלילי משוב רכים
- 🌙 מסך "לילה טוב" ועמעום הדרגתי של המסך לאורך הסשן

## מבנה הקוד

```
index.html        המסכים והמעטפת
css/              עיצוב (פלטת לילה, RTL) ואנימציות עדינות
data/countries.js כל תוכן המדינות — מופרד מהקוד
js/flags.js       דגלי SVG מצוירים
js/app.js         ניווט, מסכים, דרכון, לילה טוב
js/minigames.js   המשחקונים
js/audio.js       קריינות וצלילים
js/storage.js     שמירת התקדמות
```

הוספת מדינה חדשה = הוספת אובייקט ב־`data/countries.js` ודגל ב־`js/flags.js`.
